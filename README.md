## 📄 Published Research

### Identification and Elucidation of Therapeutic Targets in Nasopharyngeal Carcinoma: A Computational Approach

**Current Trends in OMICS, 6(1), 40–63 (2026)**
**First Author**

[![DOI](https://img.shields.io/badge/DOI-10.32350%2Fcto.61.03-blue)](https://journals.umt.edu.pk/index.php/CTO/article/view/7696)

A computational investigation of **nasopharyngeal carcinoma (NPC)** using transcriptomic data, pathway enrichment, protein–protein interaction networks, and network-based prioritization of therapeutic targets.

**Computational workflow:**

`GEO Dataset → Differential Expression → Pathway Enrichment → PPI Network → Cytoscape → Hub Gene Prioritization → Biological Interpretation`

**Key methods:**

* GEO dataset **GSE53819**
* GEO2R-based differential expression analysis
* Consensus pathway enrichment analysis
* Wilcoxon, FGSEA, and KS-based approaches
* STRING protein–protein interaction analysis
* Cytoscape network analysis
* CytoHubba / MCC hub-gene prioritization

**Key findings:**

The analysis identified **10 hub genes** and highlighted two cooperating biological modules:

🧬 **Inflammatory cytokine–chemokine axis**
`IL1B → CXCL8 → CXCL12`

🧬 **Extracellular matrix remodeling axis**
`FN1 → COL1A1`

🔗 **Publication:** [View Article & DOI](https://journals.umt.edu.pk/index.php/CTO/article/view/7696)

### 🩺 Biomedical Data Science & Machine Learning

**BMI, Endocrine Signatures & Clinical Phenotypes in PCOS**

**MPhil Bioinformatics Thesis | Submitted**

Applied statistical modeling and machine learning to a dataset of **508 patients** to investigate relationships between BMI, endocrine characteristics, ovarian features, and clinical variables.

**Methods:**

`Exploratory Analysis → Statistical Testing → Correlation Analysis → Regression → Clustering → Random Forest → ROC-AUC`

**Methods & techniques:** Random Forest · Clustering · Spearman Correlation · Mann–Whitney U · Linear Regression · Multivariable Regression · ROC-AUC

**Model performance:**

**ROC-AUC = 0.927**

compared with a:

**Lifestyle-only baseline = 0.769**

A statistically significant right-ovary association was also observed:

**β = −0.128, p = 0.024**

> This project strengthened my experience in **biomedical data analysis, statistical reasoning, predictive modeling, and biological interpretation**.
